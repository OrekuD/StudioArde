# Studio Ardē Clone

A recreation of the [Studio Ardē](https://www.studio-arde.com/) website, built as a personal frontend/design engineering project.

The original Studio Ardē website was awarded **Awwwards Site of the Day on January 20, 2024**, as well as an Awwwards Developer Award.
